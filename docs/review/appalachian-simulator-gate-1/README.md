`appalachian-simulator-review.html`, then inspect:

- `captures/` for figure-eight travel, arm circle, independent arms, all three
  jump prototypes, the eight-move line on both heroes, half speed, diagnostics,
  and keyboard/gamepad/touch evidence;
- `reports/` for motion, arms, jumps, contact audio, browser smoke, latency,

decide dance weight, animation appeal, cultural accuracy, audio taste, anatomy,
and whether the controls are genuinely fun.
